# TRelay S3 Controller

TRelay S3 Controller is a MicroPython-based Wi-Fi sprinkler/relay controller for the
LILYGO T-Relay ESP32-S3.

The project currently provides:

- Six relay outputs through the board's 74HC595 shift register.
- Existing-network Wi-Fi operation.
- NTP time synchronization.
- Optional weather lookup and weather-based event blocking.
- Persistent scheduled events and event logs.
- Relay On, Relay Off, All Relays On, All Relays Off, and GET URL events.
- Temperature, rain, and wind skip conditions.
- One-shot **Skip Next** support for scheduled events.
- A Microdot web interface and REST API.
- Versioned event records with automatic migrations.
- Uncompressed ZIP-based firmware deployment with an embedded firmware manifest.

## MicroPython requirement

The LILYGO T-Relay ESP32-S3 used by this project has 16 MiB flash and 8 MiB
Octal PSRAM. Use the MicroPython ESP32-S3 **SPIRAM_OCT** build so the PSRAM is
available to MicroPython.

## Build

From the repository root:

```cmd
python firmware\tools\build_firmware_deployment.py
```

The generated firmware image is:

```text
firmware/dist/main.zip
```

## Build and upload

```cmd
python firmware\tools\upload_sprinkler_firmware.py COM3 --build
```

For the first ZIP-based deployment:

```cmd
python firmware\tools\upload_sprinkler_firmware.py COM3 --build --install-loader
```

See `firmware/docs/BUILD_AND_DEPLOY.md` for details.

## Persistent device files

Firmware updates do not overwrite:

```text
/config.json
/events.json
```

`config.json` stores device configuration. `events.json` stores versioned
events and the event log.

See `firmware/docs/EVENTS_AND_PERSISTENCE.md`.
